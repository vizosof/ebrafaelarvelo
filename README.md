Hola a todos.

Soy estudiante de Ingeniería de Sistemas y estoy comenzando mi camino en la programación. No sé mucho todavía, pero tengo muchas ganas de aprender y mejorar.
Por eso quiero formar un grupo de aprendizaje con personas que también quieran aprender desde cero o que deseen compartir sus conocimientos.

Los temas que me gustaría estudiar en grupo son:

Programación básica

Desarrollo web (HTML, CSS, JavaScript)

Python y Flask

Git y GitHub

Buenas prácticas de código

Proyectos colaborativos

La idea es apoyarnos, resolver dudas juntos, practicar con proyectos reales y avanzar paso a paso.
No importa tu nivel: si estás empezando como yo, eres bienvenido; si ya sabes un poco y quieres ayudar, también.

Si te interesa unirte, puedes comentar aquí o contactarme.
¡La intención es aprender juntos y crecer como equipo!
